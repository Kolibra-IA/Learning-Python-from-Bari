### DATA TYPES IN PYTHON

## Numeric

- int: This represents numbers without decimals.
- Float: This represents decimals.
- Boolean: This represents true or false, and it is often used to build conditional cases.
- Complex: This represents complex numbers; Python supports scientific computation extensively.

## Sequence

- List: This represents a list of values, grouped together and bordered by squared brackets. It is indexed and mutable.
- Tuple: This represents a list of values, grouped together and bordered by round brackets. It is indexed and immutable.
- String: This represents a sequence of characters, grouped together and bordered by single or double quotes. It is indexed and immutable.

## Set

- Vector values.
- Values bordered by flower brackets.
- Mutable.
- Unique.
- Unordered.

## Dictionary

- A collection of key-value pairs.
- Mutability of the values.
- Unordered.
- Unique keys.
- Values bordered by flower brackets.
