## Program

- A program is a set of instructions given to a computer to accomplish a task or set of tasks. Broadly speaking, a program consists of two parts:

1. Data: The main elements that are manipulated and utilized.
2. Instructions: These perform operations on the data.

## Variables

- A variable is a name that refers to a value stored in a program.

## Rules

- A variable can start in a letter or underscore but not any other special character or number.
- A variable can contain alphanumerics and underscore.
